# Real Madrid — неофициальный фан-сайт

Статичный сайт: HTML + CSS + JS, без сборки.

## Разделы
Новости · Клуб · Стадион · История · Лаборатория данных

## Структура
- `index.html` — разметка всех разделов
- `style.css` — оформление (цвета в `:root`)
- `script.js` — переключение разделов, новости и демо-график
- `assets/crest.png` — **ваш файл эмблемы** (положите сюда; пока его нет, показывается монограмма «RM»)

## Что заменить своим
- Новости: массив `news` в `script.js`
- Данные графика: массив `demoData` в `script.js`
- Тексты разделов: `index.html`

## Запуск локально
Откройте `index.html` в браузере.

## Публикация на GitHub Pages
1. Загрузите все файлы (и папку `assets`) в репозиторий.
2. Settings → Pages → Branch: `main`, папка `/ (root)`.
3. Сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Сайт неофициальный и не связан с Real Madrid C.F.
